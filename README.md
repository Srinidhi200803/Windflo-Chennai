# Windflo-Chennai
WindFlo Chennai 🌧️ A climate-resilience and rainwater harvesting platform for Chennai.

About the Project

WindFlo Chennai aims to help residents prepare for heavy rainfall while encouraging sustainable water management. It combines weather forecasts, community waterlogging reports, and rooftop rainwater harvesting estimates in one platform.

Key Features

- Weather Dashboard: Displays rainfall forecasts, temperature, and humidity.
- Community Map: Shows reported waterlogging locations.
- Risk Indicator: Uses rainfall levels and recent reports to show Low, Watch, or High attention, with explanations.
- Rainwater Harvesting Calculator: Estimates how much rainwater a rooftop could collect.
- Safety Guidance: Provides practical rainfall-preparedness tips.

Technology Stack

- React and TypeScript
- Tailwind CSS
- Open-Meteo API
- Leaflet and OpenStreetMap
